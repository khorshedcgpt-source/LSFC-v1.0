# LSFC — UI/UX অডিট ও পলিশিং পরিকল্পনা

**প্রজেক্ট:** lsfc-v1_0 (Vite + React + TypeScript + Tailwind v4 + Electron)
**পরিধি:** সম্পূর্ণ সোর্স-কোড রিভিউ (App, Dashboard, ApplicationForm, CustomerLedger, ExpenseTracker, Reports, Settings, Auth, index.css, Electron, assets)
**সীমাবদ্ধতা:** অ্যাপ চালিয়ে দেখা হয়নি; সব পর্যবেক্ষণ কোড থেকে। বাস্তবায়নের পর প্রতিটি আইটেম নিজের মেশিনে চোখে দেখে যাচাই করতে হবে।

**ব্যবহারবিধি:** প্রতিটি আইটেমের একটি আইডি আছে (যেমন `A-3`)। নতুন সেশনে এই ফাইল আপলোড করে বলুন, "ধাপ A করো" বা "A-1 থেকে A-4 করো"। ধাপ শেষে `[ ]`-কে `[x]` করে ট্র্যাক করুন।

**সহায়ক নিয়ম (প্রজেক্ট-স্তরের):**
- সংক্ষিপ্ত প্রশ্নোত্তর; অনুমতি ছাড়া বাস্তবায়ন নয়
- পুরনো সিদ্ধান্ত বহাল: Electron + Firebase, রোল-হায়ারার্কি, লগইন ছাড়া কিছু দেখা যাবে না, ইনভয়েস A5 ও বর্তমান ডিজাইন অপরিবর্তিত
- ডেটা-মডেল/ফি-লজিক (`serviceCalculator`, waterfall, `invoiceStore`) এই কাজে ছোঁয়া হবে না, শুধু UI স্তর
